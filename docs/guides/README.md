# Relay — Guides

The user manual for Relay. Start here if you are setting up Relay for the first time or coming back after a break.

- **[Getting started](getting-started.md)** — install, pair, author a persona, start your first session, attach from another device, manage tokens/projects/sessions, troubleshooting.

## What belongs here

This tree is the **user manual** — narrative, task-oriented, A–Z. Distinct from:

- [`docs/prd/`](../prd/) — the specification (what Relay does and does not do)
- [`docs/arch/`](../arch/) — contributor-facing architecture (how Relay is built)
- [`docs/decisions/`](../decisions/) — the decision log (why Relay is built this way)

If a chapter here cites a behavior, it cites the resolved `D-NN` / `ND-NN` that anchors it so a reader can trace from "how do I detach?" all the way down to the design rationale. If you are building Relay rather than using it, start at [`docs/prd.md`](../prd.md) instead.
